# Bitrix Product SEO Audit

Отдельный компонент для «1С-Битрикс: Управление сайтом», который оценивает SEO-готовность товаров каталога по шкале 0–100% и показывает причины потери баллов.

- Магазин: https://bitrix.qryptoturtle.top/
- Отчёт: https://bitrix.qryptoturtle.top/seo-report/

## Возможности

- пять независимых блоков проверки по 20 баллов;
- получение стандартных SEO-полей через `InheritedProperty\ElementValues`;
- пакетная загрузка свойств через `CIBlockElement::GetPropertyValuesArray`;
- фильтрация по статусу и сортировка по оценке или названию;
- кеширование с учётом параметров отчёта;
- адаптивная таблица и конкретные рекомендации по каждому товару.

## Структура

- `local/components/candidate/product.seo.audit` — компонент и шаблон;
- `public/seo-report/index.php` — отдельная публичная страница;
- `tools/seed_catalog.php` — повторяемое создание 20 тестовых товаров;
- `compose.yaml`, `docker/` — изолированное окружение Bitrix;
- `tests/run.php` — автономные тесты формулы.

## Формула

Описание, характеристики, фотографии, meta title и meta description дают максимум по 20 баллов. Оптимальная длина описания — 300–2000 символов, title — 30–60, description — 120–160. Ключевыми считаются значимые слова из названия длиной от четырёх символов. Статусы: 80–100 — готов, 50–79 — требует внимания, 0–49 — критично.

## Локальная проверка формулы

```bash
docker run --rm -v "$PWD:/app" -w /app php:8.4-cli php tests/run.php
```

## Установка в существующий Bitrix

1. Скопировать компонент в `/local/components/candidate/product.seo.audit`.
2. Скопировать страницу в `/seo-report/index.php`.
3. Запустить `tools/seed_catalog.php` из CLI внутри окружения Bitrix.
4. Очистить управляемый кеш и открыть `/seo-report/`.

Ядро Bitrix, пользовательские загрузки, лицензия, база данных и секреты намеренно не входят в репозиторий.
