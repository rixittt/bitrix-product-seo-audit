Сайт развёрнут на Ubuntu-сервере в отдельном Docker Compose-стеке с PHP 8.4, Apache и MySQL 8.0, а внешний HTTPS-трафик принимает уже работавший на сервере Caddy. Новый магазин подключён к существующей proxy-сети изолированно, поэтому контейнеры другого проекта не переносились и не пересоздавались. Для отчёта создан полноценный компонент Bitrix с собственной папкой, `component.php`, параметрами, кешированием и адаптивным шаблоном. Оценка складывается из пяти равновесных блоков по 20 баллов: описание, характеристики, изображения, meta title и meta description. Внутри блоков учитываются не только заполненность, но и рекомендуемая длина текста, наличие нескольких характеристик и вхождение значимого слова из названия товара. Фильтрация и сортировка выполняются на сервере по whitelist-параметрам, а формула вынесена в отдельный класс и покрыта автономными тестами. После генерации заготовок вручную пришлось исправить точный поиск кодов свойств в API Bitrix, обработку граничных длин после обрезки Unicode-строк и передачу HTTPS через обратный прокси.
